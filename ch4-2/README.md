# 실습과제1

## ls 명령어의 4가지 옵션 -a, -l, -F, --help을 설명하고 각각 실행예를 첨부하시오
| 옵션 | 설명 | 실행 예 |
| -- | -- | -- |
| `-a` | 숨김 파일까지 포함하여 모든 파일과 디렉터리를 표시한다. 리눅스에서 `.`으로 시작하는 파일은 숨김 파일이다. | `ls -a` |
| `-l` | 파일과 디렉터리의 정보를 자세한 형식으로 표시한다. 권한, 소유자, 그룹, 크기, 수정 시간 등이 함께 나온다. | `ls -l` |
| `-F` | 파일의 종류를 구분할 수 있도록 이름 뒤에 기호를 붙여 표시한다. 예를 들어 디렉터리는 `/`, 실행 파일은 `*`가 붙는다. | `ls -F` |
| `--help` | `ls` 명령어의 사용법과 사용 가능한 옵션에 대한 도움말을 출력한다. | `ls --help` |

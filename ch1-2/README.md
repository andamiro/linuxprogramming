## 가상머신이란 무엇인가?
가상머신은 실제 컴퓨터 안에 소프트웨어로 만든 또 하나의 컴퓨터 환경이다.  
하나의 PC에서 여러 운영체제를 실행할 수 있고, 각각 독립된 환경처럼 사용할 수 있다.

## 가상머신을 사용하는 이유를 설명하라.
가상머신을 사용하면 하나의 컴퓨터에서 여러 운영체제를 사용할 수 있다.  
또한 프로그램 테스트나 개발 환경을 분리할 수 있어서 문제가 생겨도 실제 컴퓨터에 영향을 적게 준다.

## WSL2가 다른 가상머신 소프트웨어와 비교하여 장점이 무엇인가?
WSL2는 Windows에서 Linux 환경을 사용할 수 있게 해주는 기능이다.  
일반 가상머신보다 설치와 실행이 간단하고, Windows 파일과 Linux 환경을 함께 사용하기 편리하다.  
또한 별도의 가상머신 프로그램을 실행하는 것보다 비교적 가볍게 사용할 수 있다.

## GUI, CLI의 장단점을 비교 설명하시오.
GUI는 아이콘이나 창을 마우스로 조작하는 방식이라 사용하기 쉽고 직관적이다.  
하지만 시스템 자원을 더 많이 사용하고 반복 작업에는 불편할 수 있다.

CLI는 명령어를 직접 입력하는 방식이다.  
처음에는 사용하기 어렵지만 자원을 적게 사용하고 반복 작업이나 자동화에 유리하다.

## CLI방식의 인터페이스가 GUI방식보다 처리속도가 빠른 이유를 설명하라.
CLI는 그래픽 화면을 표시하거나 마우스 입력을 처리할 필요가 없기 때문에 사용하는 시스템 자원이 적다.  
또한 명령어를 직접 실행하므로 작업 과정이 단순해 빠르게 처리할 수 있다.

## 리눅스에서는 왜 CLI방식을 주로 사용하는가?
Linux는 서버나 개발 환경에서 많이 사용되기 때문에 CLI를 사용하면 빠르고 효율적으로 시스템을 관리할 수 있다.  
또한 명령어를 이용하면 여러 작업을 자동화하거나 원격으로 관리하기 쉽다.

## 리눅스 명령어란 무엇이고 중요 5개 명령어를 조사하라. 실행결과를 첨부하라.
리눅스 명령어는 터미널에서 입력하여 파일 관리나 시스템 작업을 수행하는 명령어이다.

- `pwd` : 현재 위치한 디렉터리를 확인한다.
- `ls` : 현재 디렉터리의 파일과 폴더를 확인한다.
- `cd` : 다른 디렉터리로 이동한다.
- `mkdir` : 새로운 디렉터리를 만든다.
- `cat` : 파일의 내용을 확인한다.

# 실습과제1

## 다음 단어 또는 기호의 의미를 설명하라.
- 디렉터리(directory): 파일이나 다른 디렉터리를 저장하고 관리하는 공간이다. Windows의 **폴더(folder)**와 비슷한 개념이다.
- 서브 디렉터리(subdirectory): 특정 디렉터리 안에 존재하는 하위 디렉터리이다.
- 작업 디렉터리(working directory): 현재 사용자가 명령을 실행하고 있는 디렉터리이다. 현재 디렉터리라고도 한다.
- 홈 디렉터리(home directory): 각 사용자에게 기본으로 할당된 개인 디렉터리이다. 로그인하면 보통 홈 디렉터리에서 작업을 시작한다.
- ~: 현재 사용자의 홈 디렉터리를 의미한다. 예: ~/Documents
- .: 현재 작업 중인 현재 디렉터리를 의미한다. 예: ./test.txt
- ..: 현재 디렉터리의 상위 디렉터리를 의미한다. 예: ../file.txt
- /: Linux/Unix에서 디렉터리를 구분하는 기호이며, 단독으로 사용하면 파일 시스템의 최상위인 루트(root) 디렉터리를 의미한다. 예: /home/user
- 상대경로(relative path): 현재 작업 디렉터리를 기준으로 파일이나 디렉터리의 위치를 나타내는 경로이다. 예: ../images/photo.jpg
- 절대경로(absolute path): 루트 디렉터리 /부터 시작하여 파일이나 디렉터리의 전체 위치를 나타내는 경로이다. 예: /home/user/images/photo.jpg

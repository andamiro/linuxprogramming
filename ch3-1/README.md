# 실습과제1

| 기능 | 단축키 |
|---|---|
| 문자 단위 커서 이동 → 앞 | `Ctrl + B` |
| 문자 단위 커서 이동 → 뒤 | `Ctrl + F` |
| 문자 단위 커서 이동 → 맨 앞 | `Ctrl + A` |
| 문자 단위 커서 이동 → 맨 뒤 | `Ctrl + E` |
| 단어 단위 커서 이동 → 앞 | `Alt + B` |
| 단어 단위 커서 이동 → 뒤 | `Alt + F` |
| 현재 위치 문자 삭제 | `Ctrl + D` |
| 뒤에 있는 문자 삭제 | `Backspace` 또는 `Ctrl + H` |
| 뒤에 있는 단어 삭제 | `Ctrl + W` |
| 자르기 및 붙여넣기 | `Ctrl + K` / `Ctrl + Y` |
| 화면 잠금 및 해제 | `Ctrl + S` / `Ctrl + Q` |
| 실행 종료 | `Ctrl + C` |
| 화면 삭제 | `Ctrl + L` |

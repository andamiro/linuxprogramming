## UNIX 운영체제에 대하여 조사하시오.
UNIX는 1960년대 후반 벨 연구소에서 개발된 운영체제이다.  
여러 사용자가 동시에 사용할 수 있고 여러 작업을 처리할 수 있으며, 안정성과 보안성이 높다.  
Linux와 macOS 등 여러 운영체제에 영향을 주었다.

## Linux, Windows, macOS 를 비교 설명하시오.
Linux는 오픈소스 운영체제로 무료이며 수정이 자유롭고 서버나 개발 환경에서 많이 사용된다.  
Windows는 Microsoft에서 개발했으며 프로그램과 게임 호환성이 좋아 일반 PC에서 많이 사용된다.  
macOS는 Apple에서 개발한 운영체제로 안정성이 높고 Apple 기기와의 연동이 좋다.

## 우분투(Ubuntu) 리눅스에 대하여 조사하시오.
Ubuntu는 Debian 기반의 Linux 배포판이다.  
무료로 사용할 수 있고 설치와 사용이 비교적 쉬워 Linux 입문자에게 많이 사용된다.  
또한 개발이나 서버 운영에도 많이 활용된다.

## 임베디드 시스템용 운영체제로 리눅스가 적합한 이유를 설명하라.
Linux는 오픈소스라서 필요한 기능만 수정해서 사용할 수 있고, 다양한 CPU와 하드웨어를 지원한다.  
또한 시스템을 가볍게 구성할 수 있고 무료로 사용할 수 있어 임베디드 시스템에 적합하다.
